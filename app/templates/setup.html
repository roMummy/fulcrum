First Run

跟着这几步做，就能把后台先跑起来

如果你现在只是先装起来试跑，直接选内置 SQLite 就可以。只有你明确要接正式数据库时，再选择 MariaDB。

01 先选数据库 大多数第一次安装，直接选“内置 SQLite”。简单、快、不用额外准备数据库。
02 创建管理员 设置一个你自己记得住的管理员用户名和密码，后面就用它登录后台。
03 安装后重启 系统会自动生成配置。你只需要按提示重启服务，再回来登录即可。

Setup Wizard

首次安装引导

推荐新手直接用 SQLite

不用研究太多参数。按顺序填完下面几项，点一次按钮就可以完成安装。

怎么选？

如果你现在不确定，就选“内置 SQLite”。只有在你已经准备好了 MariaDB，并且确定要正式部署时，再选 MariaDB。

MariaDB 环境要求与建库命令（点击展开）

版本要求：建议 MariaDB 10.6 及以上（字符集 utf8mb4）。

请在 MariaDB 管理账号下执行以下命令：

CREATE DATABASE IF NOT EXISTS `{{ form_data.db_name or 'multi_bot_admin' }}` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS '{{ form_data.db_user or 'multi_bot_admin' }}'@'%' IDENTIFIED BY '请替换为你的数据库密码';
GRANT ALL PRIVILEGES ON `{{ form_data.db_name or 'multi_bot_admin' }}`.* TO '{{ form_data.db_user or 'multi_bot_admin' }}'@'%';
FLUSH PRIVILEGES;

如果你只允许本机访问，请把 '%' 改成 'localhost'。

你需要知道的就这几件事

1. SQLite 会直接用项目内置数据库，不需要你额外准备东西。

2. MariaDB 只有在你已经有数据库地址、账号、密码时才需要填写。

3. 安装完成后一定要重启服务。重启后再次打开后台，就会进入登录页。
