# 群成员邀请关系图谱设计

日期：2026-11-14。用户已确认将邀请树改为层级关系图谱。

## 展示与交互

- 群详情「成员」中直接展示邀请关系图谱，成员使用头像卡片，自上而下通过箭头连接邀请人与被邀请人。
- 沿用当前 Soft UI 的浅色表面、靛紫强调和圆角，画布使用轻量网点辅助辨识位置。
- 支持拖动画布、缩放按钮、适应画布、搜索姓名或成员 ID 定位、展开全部和收起分支。
- 初始展开第一层邀请关系；单个分支可独立展开。选中成员后展示完整身份、邀请人、证据来源、记录时间和直接邀请人数。
- 提供放大弹窗，页面和弹窗共用同一画布与交互状态；关闭后回到原入口并恢复键盘焦点。
- 无任何有效邀请边的成员单独列在「未关联成员」，仍可搜索及查看详情。有邀请下级但上级未知的根节点保留在图中并标明「邀请人未知」。

## 数据与边界

- 继续使用当前保存的唯一邀请快照，不扩展协议能力，也不改变同步或历史补查的写入行为。
- 图谱依旧使用成员 ID 关联，同名不合并；退群成员与不在当前名册的邀请人保留说明。
- 复用现有迭代森林生成，循环仅切断展示边并保留原始邀请证据与提示；深层链不采用递归布局。
- 没有关系时显示明确空状态，不将群主默认连到其他成员。未知人数包含图中上级未知的根节点，未关联人数只统计没有任何展示边的成员。
- 不新增数据库字段、第三方图表框架或远程资源。使用原生 DOM 卡片、SVG 连线与浏览器指针事件。
- 删除旧缩进树的模板标记、样式和脚本路径，更新当前测试，不保留双份展示或旧入口。

## 可访问性与验证

- 保留成员表格及邀请人列作为精确资料视图。图谱卡片与分支按钮可键盘访问；画布提供方向键平移、加减键缩放及归位快捷键。
- 搜索结果显示姓名和 ID，支持定位被折叠的深层成员以及未关联成员。普通滚轮继续滚动页面，缩放按钮和触控拖动用于操作画布。
- 弹窗遵循当前共享关闭、Esc 与背景遮罩行为，恢复可见入口焦点。
- 执行邀请数据及真实群详情路由的定向测试、JS 语法检查与 Python/Jinja 基础检查。
- 在 1440、1024、390 三个视口检查布局与页面宽度，验证缩放、拖动、分支、同名搜索定位、空状态、循环提示、详情和弹窗焦点。
- 浏览器数据使用本地临时数据库构造，不代表微桥真机已取得邀请信息。本轮完成代码与提交，部署继续沿用用户后续明确指令。
