# 套餐价格居中与 Swiss Hero 交互设计

## 背景

全站 Swiss Style 上线后，公开套餐价格页在桌面和移动端都出现整体向左偏移。真实 Chromium 复现显示：`1536px` 视口中的套餐网格宽度为 `1200px`，但左边界是 `0`，正确居中时左右应各保留 `168px`；`390px` 视口中的网格宽度为 `350px`，但左边界仍是 `0`，正确布局应保留 `20px` 左右边距。

根因是 `.marketing-plan-grid` 与 `.marketing-section-inner` 同时作用于价格页网格。后声明的营销网格规则使用 `margin: 0`，覆盖了共享内容容器的 `margin: 0 auto`。首页套餐区没有暴露该问题，是因为它的网格位于已经居中的 `.marketing-section-inner` 内部。

用户同时确认删除营销首屏中的控制台截图，并使用模板 Hero 的交互要求呈现首屏。新 Hero 必须继续保持 Swiss Style 的黑白网格、信号红和明确转化路径，但不再依赖图片、渐变、SVG 插画或新的前端框架。

现有品牌标志也存在明显割裂：浏览器图标仍是蓝绿渐变圆角机器人，站内顶部则使用红底“曜”字，两者无法形成统一识别。用户确认同步重做 Logo，并明确浏览器 favicon 保留圆角外轮廓，其余细节按 Swiss Style 方向统一。

## 设计目标

1. 套餐价格页在桌面和移动端恢复稳定居中，左右留白与站点页头、页脚一致。
2. 删除首屏控制台截图节点、图片样式引用和要求该素材存在的旧测试契约。
3. 使用全屏 DOM 几何场景承载 Hero 视觉，保留“曜枢 AI”、价值主张、转化按钮和试用说明。
4. 通过指针、按钮聚焦和键盘操作提供轻量反馈，同时尊重系统减少动态效果设置。
5. 保持单一实现路径，不增加旧截图回退、主题开关或双套 Hero。
6. 统一营销站、双后台、认证页和浏览器图标的品牌几何语言，删除旧渐变机器人和文字方块标记。

## 品牌标志

Logo 使用抽象 `Y` 作为“曜枢”的首字母识别，并以中心蓝色小方块表达“枢点”和多渠道连接。主体保持信号红、纯白几何和信息蓝三种已确认 Swiss 色值，不使用文字描边、渐变、阴影或机器人图形。

站内标志使用直角红色方形，适配 `36px` 顶栏和认证区尺寸；浏览器 favicon 使用相同内部几何，但外层红色方形使用明确圆角并保留透明边角，满足浏览器标签页的小尺寸辨识。两个 SVG 只允许外轮廓不同，内部图形必须保持同一坐标和比例。

站内模板使用装饰性空 `alt` 的 `<img>`，相邻“曜枢 AI”文字继续承担可访问名称。旧 `<span>曜</span>`、蓝绿渐变定义和圆角机器人路径直接删除，不保留备用入口。

## 套餐页布局修复

共享三列网格规则继续负责 `display`、列数、间距、内边距和列表重置，但不再统一重置外边距。只有语义上需要清除浏览器默认外边距的 `.marketing-steps` 单独使用 `margin: 0`。

这样 `.marketing-section-inner.marketing-plan-grid` 会自然继承共享容器的 `margin: 0 auto`，首页和企业套餐页中的普通 `.marketing-plan-grid` 仍保持原有内部网格行为。该修复直接消除冲突源，不通过额外高优先级选择器覆盖症状。

## Hero 结构

营销首屏继续使用单个 `.marketing-hero` 作为全宽舞台，内部只保留两个一级区域：

1. `.marketing-hero-scene`：纯展示的几何交互层，使用 `aria-hidden="true"`，不进入读屏顺序。
2. `.marketing-hero-copy`：现有品牌标题、价值主张、按钮和试用说明，继续作为页面唯一主标题和主要转化入口。

几何场景由少量普通 DOM 元素组成：一条横向轴、一条纵向轴、一个红色主信号块、一个蓝色次级标记和短编号标识。所有元素使用直角、纯色和硬边界，不生成 SVG，不使用渐变、阴影、光斑或装饰卡片。

红色主信号块位于首屏右上构图区域，避免遮挡左侧正文。蓝色标记只承担交互方向提示，不与主要转化按钮争夺视觉焦点。轴线使用低对比灰色，并控制数量，避免重新引入线条过多的问题。

## 交互规则

新增一个原生 JavaScript 文件，只在存在 `[data-hero-scene]` 时工作：

1. 指针在 Hero 内移动时，将相对中心位置收敛为 `-1` 到 `1`，通过 CSS 自定义属性传递给场景。
2. 红色信号块最多移动约 `12px`，蓝色标记以更小幅度反向移动，形成明确但克制的空间反馈。
3. 指针离开 Hero 后，自定义属性回到零，场景平滑归位。
4. 当主要按钮获得键盘焦点时，CSS 使用 `:focus-within` 提升红色信号块的边界和位置反馈，不要求鼠标参与。
5. 当系统启用 `prefers-reduced-motion: reduce` 时，脚本不绑定指针移动，CSS 关闭过渡和位移，页面保持完整静态构图。

脚本不读取业务数据，不发送请求，不创建计时器，也不影响页面导航和表单行为。

## 响应式设计

桌面端保持左侧正文、右侧几何信号的非对称 Swiss 构图。`820px` 以下缩小主信号块并降低位移幅度；`560px` 以下将几何场景移到标题后方的右上区域，确保标题、按钮和试用说明不被遮挡。

套餐页继续在 `820px` 以下切换为单列。修复后 `1536px` 视口的套餐网格左右留白应一致，`390px` 视口左右边界应分别为 `20px` 和 `370px`，页面根节点不得出现横向溢出。

## 文件范围

- 修改 `app/templates/marketing_home.html`：删除截图节点，增加几何场景节点。
- 修改 `app/templates/marketing_base.html`：加载原生 Hero 交互脚本。
- 修改 `app/templates/base.html` 与 `app/templates/marketing_base.html`：统一使用新站内品牌标志。
- 新增 `app/static/js/marketing.js`：实现受限指针反馈和减少动态效果处理。
- 新增 `app/static/brand-mark.svg`：直角 Swiss 站内标志。
- 修改 `app/static/favicon.svg`：改为共享几何、圆角外轮廓的浏览器图标。
- 修改 `app/static/css/style.css`：修复套餐网格外边距冲突，替换截图样式为几何场景样式。
- 修改 `tests/test_swiss_ui.py`：建立居中、无截图、交互场景和减少动态效果契约。
- 修改 `tests/test_public_marketing_pages.py`：删除旧截图素材断言，改为当前 Hero 结构断言。

不修改套餐业务数据、价格计算、路由、注册流程、数据库模型或后台页面。

## 验证策略

1. 先增加会在当前实现失败的静态契约测试，证明偏移样式和旧截图链路仍然存在。
2. 运行 `tests/test_swiss_ui.py` 与营销页定向测试，确认新结构和公开价格数据不受影响。
3. 使用真实 Chromium 在 `1536x960` 与 `390x844` 视口截图 `/` 和 `/pricing`。
4. 读取套餐网格、卡片、Hero 正文和几何信号块的边界，检查左右留白、遮挡和根节点横向溢出。
5. 在浏览器中触发指针移动与主要按钮聚焦，确认 CSS 自定义属性和元素位移发生变化；在减少动态效果环境中确认位移关闭。
6. 检查站内标志在营销、双后台与认证页均使用同一 SVG，并确认 favicon 具有圆角且不包含渐变。
7. 只重建并替换应用容器，随后验证 `8280/healthz`、`8280/readyz` 和容器健康状态。
