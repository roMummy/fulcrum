# 插件功能卡片改版设计

日期：2026-11-14。用户已确认采用推荐方案，并要求直接实施。

## 目标与范围

当前企业插件页 `/plugins` 和平台插件管理页 `/platform/plugins` 的卡片最小宽度均为 250px。企业页只显示单行说明且没有版本号，平台页没有功能介绍。本次将两页统一为更大的功能卡片，方便用户直接理解每个插件的用途和当前版本。

## 已确认方案

- 桌面默认三列，平板两列，手机一列，卡片间距约 20px、内边距 20px。
- 卡片上方显示 48px 的插件标识、可换行名称和独立版本徽标；平台启停开关放在右上方。
- 卡片中部完整显示现有功能介绍，允许长文自然撑高，删除企业页的一行截断样式。
- 底部对齐开发者信息和现有配置入口；平台页底部保留可见范围、使用情况和历史版本等操作。
- 沿用现有 Soft UI 的白色表面、靛紫色、圆角和柔和阴影，用排版和间距体现层次。

比较过保留紧凑小卡片、放大为双列卡片两种方向：前者无法解决介绍难读的问题，后者在常见桌面下每屏可浏览的插件更少。用户选择三列功能卡片方案。

## 数据与交互

直接使用现有 `Plugin.display_name`、`version`、`description`、`author`，不新增接口、数据库字段或插件扫描。版本缺失明确显示“版本未声明”，介绍缺失显示“暂未提供功能介绍”。模板保持自动转义。

企业页继续展示清单错误与警告，配置和扩展管理使用当前入口。平台页沿用现有 `data-pp-*`、开关、搜索、筛选及弹窗协议。搜索提示与可搜索的功能介绍保持一致。
