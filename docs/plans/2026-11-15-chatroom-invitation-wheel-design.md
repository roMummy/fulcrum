# 邀请关系图谱滚轮缩放设计

用户明确要求在现有邀请图谱增加普通滚轮放大、缩小。本次沿用已确认的图谱和部署安排，交互无需再次确认。

## 交互与实现

采用画布内普通滚轮直接缩放：向上放大、向下缩小，以鼠标指向的图谱位置为中心。继续使用现有 `zoom()` 的视图变换和缩放上下限，按钮、键盘、拖动画布共用同一个视图状态。放大弹窗移动原工作区，因此自动拥有同一套滚轮交互。

现有 Ctrl + 滚轮条件无法满足直接使用滚轮的要求；整页监听会影响画布外的浏览。仅在图谱画布的现有监听器接入普通滚轮，画布外、空图谱和纯横向滚动继续保持页面原有行为。

将像素、行、页三种滚动单位统一后计算缩放比例，限制单次输入幅度，避免鼠标滚动一格时大幅跳变。保留非被动监听以阻止画布滚轮同时滚动页面，并更新画布操作提示。

## 范围与验证

只修改 `app/static/js/chatroom-invitations.js` 的滚轮处理和 `app/templates/_chatroom_invitations.html` 的操作提示，不变更邀请关系数据或同步接口。

使用 JavaScript 语法检查、差异检查及真实浏览器定向验证，覆盖普通滚轮方向、鼠标锚点、画布内外页面滚动、缩放上下限、放大弹窗、原按钮和拖动。通过后以中文提交并部署到 192.168.2.201，核对静态资源与服务健康。
