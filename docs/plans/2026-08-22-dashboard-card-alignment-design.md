# 总览页卡片对齐设计

## 背景

企业总览页包含多组双列工作表面。通用样式为相邻的 `.work-surface` 增加顶部外边距，这条规则在普通纵向页面中用于分隔区块，但进入 CSS Grid 后会让同一行右侧卡片产生额外下移，形成明显的高低错位。卡片内容数量不同时，错位会进一步放大。

平台概览页当前只有一个主要工作表面，不存在双列卡片错位，但顶部指标带的说明文字长度不同，需要统一标题、数字和说明的内部排列。

## 目标

1. 企业总览同一网格行中的卡片顶部和底部保持对齐。
2. 卡片高度继续由实际内容决定，不设置容易溢出的固定高度。
3. 平台概览指标中的标题、数字和说明保持稳定的纵向节奏。
4. 移动端单列布局保持自然高度，不产生大块无意义留白。
5. 不改变其他详情页、列表页和业务表面的通用卡片间距。

## 方案

### 企业总览

为企业总览的双列容器增加专用类，并只对其直接子级 `.work-surface` 重置外边距。网格继续使用默认的拉伸行为，使同一行卡片自动匹配较高一侧的高度。

卡片内部使用纵向弹性布局，让标题区和内容区保持稳定结构；图表、排名、告警和任务区域仍根据真实数据自然扩展，不裁剪、不滚动、不填充伪数据。

### 平台概览

为平台指标带增加专用内部布局规则。每个指标项按“标签、数值、说明”三段排列，说明区域占据剩余空间，使不同长度文案在视觉上保持一致。

最近租户表格仍保持单个工作表面，不增加无意义的等高约束。

### 响应式

桌面端双列卡片按每一行自动等高。移动端切换为单列后，卡片恢复自然高度，区块间距完全交给网格 `gap` 管理。

## 验证

1. 执行与总览模板和样式直接相关的定向测试或模板检查。
2. 执行 `git diff --check`。
3. 在桌面和移动端访问企业总览、平台概览，确认同排卡片边缘一致、内容不溢出、单列布局无额外空白。
4. 不执行全量回归测试。
